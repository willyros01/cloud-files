iCloud Drive

Apple's iCloud Drive opens in a browser page. Use it to browse, upload and download your cloud files.

Upload a Fire file to iCloud

  1. Open iCloud Drive.
  2. Go to the iCloud folder where you want the file.
  3. Tap Upload, then Choose Files.
  4. Select the file from the Fire.

When you are on Apple's iCloud website, use the Fire browser's Back control to return here; this app cannot place its own button inside Apple's webpage.
