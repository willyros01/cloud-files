CLOUD FILES v1.6.8 — RESTORE v1.5.1 NAVIGATION MODEL
Date: 2026-09-01

CHANGES
- Removed automatic return/session restoration logic entirely.
- iCloud Drive now opens independently in a new tab using the same basic method as v1.5.1.
- No attempt is made to detect download completion.
- No attempt is made to auto-open Local Files after iCloud.
- Local Files remains a separate manual action from the Home screen and uses the native Fire file picker.
- This avoids the blank-screen behavior caused by return-navigation logic.
- Version: 1.6.8.
