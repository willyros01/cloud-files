CLOUD FILES v1.6.6 — RESTORED FIRE NATIVE LOCAL PICKER
Date: 2026-09-01

CHANGE
- Restored the proven v1.5.1-style native Fire file picker behavior.
- Download screen now has "Open Local Files Browser".
- That button directly launches the Fire/Silk native file picker.
- After a file is selected, Cloud Files opens the Local Files screen and displays the selected file details.
- This avoids depending on automatic browser Back behavior that produced blank screens.
- iCloud remains separate because Apple's page cannot signal Cloud Files when a download is complete.
- No Recent Files history was reintroduced.
- Local Files remains a browser/check utility only.
- Version: 1.6.6.
