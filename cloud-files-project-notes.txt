CLOUD FILES — FIRE HD 8 BUILD
Version: 1.4
Date: 2026-09-01

FINALIZED CAPABILITIES
- Polished tablet-friendly UX.
- iCloud Drive button opens Apple's iCloud Drive website.
- iCloud downloads go to the browser/device's normal download location.
- Cloud Files does not offer or imply destination-folder selection for iCloud downloads.
- Local Files lets the user browse/select an existing Fire file and view basic metadata.
- Cloud Files does not move, rename, delete, or reorganize local Fire files.
- Grid/List display toggle for recent local files.
- Grid/List preference saved in browser localStorage.
- Automatic day/night mode based on calculated local sunrise and sunset.
- Manual Auto -> Day -> Night override.
- If location permission is unavailable, fallback is 7:00 AM / 7:00 PM.
- Google Drive/OAuth/Apps Script relay remains removed.

DEPLOYMENT
Replace index.html and privacy.html in the root of the GitHub cloud-files repository.
Site: https://willyros01.github.io/cloud-files/
