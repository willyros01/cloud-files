CLOUD FILES v1.7.2
Date: 2026-09-01

EXPERIMENTAL RETURN RESET
- Before opening iCloud from the Download instruction page, Cloud Files stores a return target of "downloadPage".
- When Cloud Files regains control, it forces the app back to the Download instruction page on:
  - page load / pageshow
  - window focus
  - visibility returning to visible
- Uses both sessionStorage and localStorage for resilience.
- Added a small Reset Download Page fallback button on the Download instruction screen.
- iCloud still opens in a separate tab.
- This cannot force Apple/Silk to bring the Cloud Files tab to the foreground, but if Cloud Files becomes active again, it should reset to Download automatically.
- Version: 1.7.2.
