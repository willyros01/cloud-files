CLOUD FILES v1.6.3 — FIRE DOWNLOAD RETURN FIX
Date: 2026-09-01

FIX
- Removed separate-tab/window behavior for iCloud transfer screens.
- iCloud now opens in the SAME Silk tab to avoid blank tabs/screens after download.
- Download workflow stores a temporary return target in sessionStorage.
- After downloading in iCloud, press the Fire browser Back control.
- Cloud Files then automatically opens the Local Files screen.
- Local Files explains that Fire/Silk normally places downloads in Downloads.
- Upload workflow also uses the same tab but returns normally to the app.
- No attempt is made to detect download completion directly because Apple's iCloud page is cross-origin and controlled by Apple.
- Version: 1.6.3.
