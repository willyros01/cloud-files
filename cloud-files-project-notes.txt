CLOUD FILES v1.6.2 — GUIDED APPLE TRANSFER WORKFLOW
Date: 2026-09-01

CHANGES
- Home Upload and Download buttons now open separate guided screens.
- Upload screen has its own Back button and Apple-specific upload steps.
- Download screen has its own Back button and Apple-specific download steps.
- Both guided screens open Apple's real iCloud Drive webpage.
- Upload: open destination iCloud folder -> Apple Upload -> Choose Files -> select Fire file.
- Download: select iCloud file -> Apple Download -> Silk saves to normal Fire download location.
- Cloud Files does not modify Apple's toolbar or perform the transfer itself.
- Local Files remains a small secondary browser below the main iCloud panel.
- Fire HD 8 compact layout and vertical scrolling retained.
- Version: 1.6.2.
