Privacy Policy

Cloud Files is a browser-based helper for opening iCloud Drive and browsing files stored on the local device.

Files and data

Cloud Files does not upload selected local files to its own server. Recent-file entries stored by the app contain only basic metadata such as name, type and size and are kept in the browser's local storage on the device.

Location

If you allow location access, Cloud Files uses the device coordinates locally in the browser only to calculate approximate sunrise and sunset times for automatic day/night appearance. The location is not sent to the Cloud Files developer or stored by the app.

iCloud Drive

The iCloud Drive button opens Apple's iCloud website. Sign-in, browsing, uploads, downloads and storage are handled by Apple. Download destination is controlled by the browser/device, not by Cloud Files.

Local file access

Cloud Files can display basic information about a local file you explicitly select. It does not move, rename, delete, or reorganize files on the device.

Accounts and tracking

Cloud Files does not provide a separate account and does not include advertising or analytics in this version.
