My Cloud Files — Privacy Policy

Privacy Policy

Last updated: August 31, 2026

My Cloud Files is a web application that helps you access and transfer files between storage services and your device. This privacy policy describes how the application handles information when you use it.

Files You Select

My Cloud Files allows you to select a file from your device using the device's file picker. The application uses the selected file only for functions you request, such as displaying basic file information or uploading that file to Google Drive.

The application does not intentionally collect or maintain a separate copy of your selected files on a My Cloud Files server.

Google Drive

If you choose to connect Google Drive, My Cloud Files uses Google's OAuth authorization process to obtain temporary authorization to perform the requested Google Drive operation.

The application requests the Google Drive drive.file scope. This limits the application's Drive access to files it creates or that you explicitly make available to the application.

When you choose to upload a file, the selected file is transmitted to Google Drive using Google's Drive API. My Cloud Files does not intentionally sell, rent, or share your Google Drive files with advertisers or other third parties.

Google Account Information

My Cloud Files does not ask for your Google password. Google handles your authentication and authorization. The application uses the authorization information supplied by Google to perform the Drive operations you request.

A Google OAuth client secret is not stored in or required by the client-side My Cloud Files webpage.

iCloud Drive

The iCloud Drive button opens Apple's iCloud Drive web interface. My Cloud Files does not receive your Apple ID password or intentionally collect the contents of your iCloud Drive through that link.

Information We Collect

The current My Cloud Files webpage does not have a My Cloud Files account system, advertising system, or analytics system. It does not intentionally collect personal information for a separate My Cloud Files database.

Third-Party Services

My Cloud Files uses third-party services when you choose to use their features, including Google Drive and Apple's iCloud Drive web interface. Those services operate under their own privacy policies and terms.

Changes to This Policy

This policy may be updated if the functionality of My Cloud Files changes. The latest version will be published on this page.

Contact

For questions about this privacy policy or My Cloud Files, please contact the application developer using the developer contact information associated with the Google Cloud OAuth configuration.
